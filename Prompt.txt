Tu es un développeur Full-Stack senior spécialisé en React, Node.js, Express, MySQL/TiDB Cloud, UX/UI moderne et applications web responsive.

Je veux développer une application web moderne de catalogue de produits pour une entreprise.

OBJECTIF DU PROJET
------------------
Créer une plateforme permettant à une entreprise de présenter ses produits avec leurs photos, descriptions, catégories, prix et disponibilité.

Les visiteurs peuvent :
- consulter les produits ;
- rechercher des produits ;
- filtrer par catégorie ;
- consulter les détails d'un produit ;
- ajouter des produits au panier ;
- modifier les quantités ;
- voir le total ;
- envoyer leur commande via WhatsApp ;
- envoyer leur commande via Email.

L'entreprise possède également un espace d'administration sécurisé permettant de gérer entièrement le catalogue.

IMPORTANT :
Ce projet ne comporte PAS de paiement en ligne dans cette version.
La commande finale est envoyée au vendeur via WhatsApp ou Email.
